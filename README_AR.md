# Ninja ModSkin — نسخة المشروع الأولية

هذه نسخة مصدر كاملة قابلة للتعديل، وليست EXE نهائياً. أعددنا الواجهة، تسجيل الدخول عبر API، فحص الجلسة المحفوظة، تنزيل الحزمة من GitHub Releases، وتشغيل ADB دون نافذة CMD.

## ما الذي يعمل الآن؟
- واجهة تسجيل دخول عربية.
- خيار تذكر الجلسة؛ عند التشغيل التالي يعاد التحقق منها عبر الإنترنت، ولا يوجد دخول دون اتصال.
- تنزيل `modskin_payload.zip` من رابط GitHub Release.
- فحص SHA-256 اختياري للحزمة.
- تشغيل ADB في الخلفية مع إخفاء نافذة الطرفية.
- زر «جاهز» ينفذ خطوات BAT بعد تأكيد المستخدم.

## ما الذي يحتاج أن نضبطه معاً؟
1. إنشاء مستودع GitHub.
2. رفع ملفات الحزمة كـ Release asset باسم `modskin_payload.zip`.
3. وضع رابط التنزيل الصحيح في `config.json`.
4. إنشاء خدمة تحقق للحسابات (API) وربطها في `auth_api_url`.

**تنبيه أمني:** GitHub مناسب لاستضافة ملفات البرنامج والإصدارات. لكنه ليس قاعدة حسابات خاصة آمنة لتطبيق عميل؛ لا تضع كلمات المرور أو GitHub Personal Access Token داخل البرنامج أو مستودع عام. سنربط تسجيل الدخول بخدمة API تحتفظ ببيانات الحسابات على الخادم، ويمكن أن تستخدم مستودعاً خاصاً كمصدر إداري للبيانات.

## تجهيز بيئة التطوير
- Windows 10/11
- Python 3.10 أو أحدث (يفضل 3.12 حالياً لتوافق الحزم)

افتح CMD داخل مجلد المشروع ونفّذ:

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```

## إنشاء EXE
شغّل `build_exe.bat`. الناتج سيكون داخل `dist\NinjaModSkin\`.

## تجهيز ملف الحزمة الذي سيرفع إلى GitHub
داخل مجلد `payload` توجد بنية `Data` المطلوبة. أنشئ ZIP بحيث يكون `Data` في جذر الملف المضغوط، وسمّه:

`modskin_payload.zip`

يمكن استخدام أمر PowerShell من جذر المشروع:

```powershell
Compress-Archive -Path .\payload\Data -DestinationPath .\modskin_payload.zip -Force
```

ثم ارفع الملف كـ Release asset في GitHub.

## عقد خدمة تسجيل الدخول المطلوبة
`POST /login` مع JSON:

```json
{"username":"demo","password":"...","device":"PC-NAME"}
```

استجابة النجاح:

```json
{"ok":true,"token":"temporary-session-token"}
```

`GET /validate` مع ترويسة `Authorization: Bearer temporary-session-token`.

استجابة النجاح:

```json
{"ok":true}
```

الرفض يجب أن يرجع `{"ok":false,"message":"سبب الرفض"}`. يجب أن تنفذ الخدمة تحديد المحاولات، انتهاء صلاحية الجلسات، وإيقاف الحسابات من جهة الخادم.

## ملاحظات
- لا يوجد وضع Offline؛ يلزم الإنترنت عند تسجيل الدخول وعند التحقق قبل الإجراء.
- قد يؤدي تعديل ملفات اللعبة إلى مخالفة شروط اللعبة أو حظر الحساب. استخدم ملفات مصرحاً بها فقط. لا توجد أي آلية لتجاوز أنظمة الحماية أو مكافحة الغش.
- لا تشارك كلمات المرور أو مفاتيح GitHub في المحادثة.
